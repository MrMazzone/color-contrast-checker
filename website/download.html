Install notes

Windows

Run ColorContrastChecker-Windows-Setup.exe. It installs for your user account only, so it doesn’t need administrator rights. Because the installer is new, Windows SmartScreen may show “Windows protected your PC”. Choose More info, then Run anyway.

Prefer not to install? Unzip the portable download anywhere and run ColorContrastChecker.exe.

macOS

Open the .dmg and drag Color Contrast Checker into Applications. The app is signed and notarized by Apple, so it opens normally the first time.

Linux

For the AppImage, make it executable, then run it:

chmod +x ColorContrastChecker-Linux-x86_64.AppImage
./ColorContrastChecker-Linux-x86_64.AppImage

On Debian, Ubuntu and derivatives you can install the .deb instead:

sudo apt install ./ColorContrastChecker-Linux-amd64.deb

The eyedropper uses your desktop’s color picker through xdg-desktop-portal, which GNOME and KDE include. On X11 without a portal, the app shows its own magnifier instead.

Build from source

The app is written in Flutter. Clone the repository and follow the README.
